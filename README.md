# AV Switcher for Decky Loader

**Русский** | [English](README.en.md)

Версия 0.6.0.

Переключает и показывает устройства в Gaming Mode:

- единственный активный монитор (встроенный экран / HDMI / DisplayPort);
- аудиовыход (HDMI, динамики, USB-гарнитура, Bluetooth и т. п.);
- источник записи / микрофон;
- активное сетевое подключение: кабель или Wi‑Fi.
- проверка и включение Wake-on-LAN с отображением IP- и MAC-адреса.
- состояние сервера сна и выключения `magicpacket.service`.

## Сборка

```sh
pnpm install
pnpm run build
```

Для ручной установки скопируйте `plugin.json`, `package.json`, `main.py`, `LICENSE` и каталог `dist` в каталог плагина `~/homebrew/plugins/av-switcher` на Steam Deck, затем перезапустите Decky Loader.

## Как работает

Аудиоустройства переключаются через PipeWire/WirePlumber (`wpctl`). Их технические PipeWire-имена сокращаются до понятных подписей по типу подключения.

Для выбранного Bluetooth-устройства плагин также показывает доступные профили/кодеки, которые PipeWire публикует через PulseAudio-совместимый интерфейс (`pactl`). Переключение между A2DP и HFP/HSP влияет одновременно на наушники и микрофон: A2DP даёт более качественный звук, а профиль гарнитуры включает микрофон ценой качества воспроизведения. Если устройство не сообщает несколько Bluetooth-профилей, меню кодека скрыто.

Тип сети определяется по интерфейсу, через который проходит основной маршрут в интернет. Значение автоматически обновляется каждые 10 секунд.

В сетевом блоке также отображается состояние пользовательской службы `magicpacket.service`, которая обслуживает HTTP-команды сна и выключения. Показатель обновляется автоматически вместе с остальными устройствами.

## Wake-on-LAN

Wake-on-LAN позволяет разбудить компьютер с iPhone перед игрой или использованием телевизора, не подходя к кнопке питания. Телефон отправляет специальный Magic Packet на MAC-адрес сетевого адаптера. AV Switcher настраивает принимающий компьютер; пакет отправляется отдельным WOL-приложением на телефоне.

### Как пользоваться с iPhone

1. Подключите компьютер по Ethernet, откройте AV Switcher в Decky и включите Wake-on-LAN, если показана соответствующая кнопка.
2. Запишите отображаемые IP- и MAC-адреса. Для Ethernet и Wi-Fi MAC-адреса разные: используйте адрес нужного адаптера.
3. Подключите iPhone к той же локальной сети. В приложении с поддержкой Wake-on-LAN добавьте MAC компьютера, широковещательный адрес своей подсети и UDP-порт, обычно 9. Например, для сети `192.168.0.0/24` broadcast — `192.168.0.255`; для другой маски адрес может отличаться.
4. Переведите компьютер в сон и отправьте Magic Packet. Сначала проверьте пробуждение из сна, затем, если требуется, из выключенного состояния.

Работа зависит от сетевого адаптера, его питания во сне, драйвера, BIOS/UEFI и режима сна. USB-док может обесточиваться; пробуждение после полного выключения не гарантируется. Wake-on-WLAN работает только при поддержке Wi-Fi-адаптера и драйвера. Надпись «включён» подтверждает настройку, но не заменяет реальную проверку пробуждения. Гостевая Wi-Fi-сеть, изоляция клиентов и некоторые VPN блокируют широковещательные пакеты.

### Что настраивает плагин

Плагин автоматически проверяет режим пробуждения проводного сетевого адаптера при запуске и показывает текущие IP- и MAC-адреса. Если Magic Packet выключен, появляется кнопка «Включить Wake-on-LAN». После успешного включения настройка сохраняется в активном профиле NetworkManager, а кнопка скрывается.

При активном подключении по Wi‑Fi плагин показывает IP- и MAC-адрес беспроводного интерфейса и отдельно проверяет Wake-on-WLAN. Кнопка включения сохраняет `802-11-wireless.wake-on-wlan=magic` в активном профиле NetworkManager и сразу включает триггер `magic-packet` в беспроводном драйвере через `iw`.

## Сервер управления питанием

Плагин проверяет состояние пользовательской службы `magicpacket.service`. Она нужна для отправки компьютеру команд сна и выключения с iPhone. Это отдельная часть системы: Wake-on-LAN будит компьютер, а работающий HTTP-сервер позволяет снова усыпить или выключить его. Пока компьютер спит, HTTP-сервер недоступен.

Исходники восстановленного сервера находятся в [`power-server`](power-server/README.md): там описаны установка, автозапуск, настройка iPhone и HTTP API на порту **5154**, включая перезагрузку. Сам плагин не устанавливает и не запускает эту службу; без неё переключение устройств и настройка Wake-on-LAN продолжают работать.

Сервер сохраняет исходный протокол без авторизации: используйте его только в доверенной локальной сети и не открывайте порт в интернет.

## Переключение экрана

В SteamOS Gaming Mode экранами управляет Gamescope, поэтому XRandR там не работает. Плагин сначала пробует runtime-переключение Gamescope. Если установленная версия его не поддерживает, используется контролируемое DRM hotplug-переключение с автоматическим восстановлением исходных разъёмов при неудаче. Выбранный выход также сохраняется как приоритет следующего запуска, но текущая сессия не перезапускается — запущенные игры и Kodi не должны закрываться.
